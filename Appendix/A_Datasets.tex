% --------------------------------------------------- %
\subsubsection{horse2zebra}

\textbf{数据来源：}伯克利官方提供的原始数据集，包含 939 张马和 1177 张斑马的图片。

\textbf{数据下载链接：}
\url{https://efrosgans.eecs.berkeley.edu/cyclegan/datasets/horse2zebra.zip}

% --------------------------------------------------- %
\subsubsection{apple2orange}

\textbf{数据来源：}伯克利官方提供的原始数据集，包含 996 张苹果和 1020 张橙子的图片。

\textbf{数据下载链接：}
\url{https://efrosgans.eecs.berkeley.edu/cyclegan/datasets/apple2orange.zip}

% --------------------------------------------------- %
\subsubsection{summer2winter\_yosemite}

\textbf{数据来源：}伯克利官方提供的原始数据集，包含 1273 张夏季和 854 张冬季约塞米蒂国家公园的图片。

\textbf{数据下载链接：}
\url{https://efrosgans.eecs.berkeley.edu/cyclegan/datasets/summer2winter_yosemite.zip}
